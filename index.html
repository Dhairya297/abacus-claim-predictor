Pipeline
How It Works
1
Input Feature Pipeline
Claim fields (provider ID, diagnosis code, procedure, billed amount) are transformed into model-ready features via RealtimeFeaturePipeline.
2
XGBoost Prediction + SHAP
Model loaded from S3 predicts denial probability. SHAP values identify the top contributing features and translate them to human-readable reasons.
3
RAG Policy Lookup
FAISS vector search retrieves the most relevant policy chunks. OpenAI GPT summarises them into a concise, claim-specific policy note.
4
Agent Recommendations
An AI agent generates specific corrective actions and next steps, logged to S3 and returned to the Streamlit UI.
